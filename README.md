# 行こっ家 グアム旅行プラン

日付を非公開にした家族旅行用サイトです。

## 特徴

- GitHub Pagesだけで動作する静的サイト
- スマートフォン対応
- ToDoのチェック状態を端末内に保存
- Service Workerによるオフライン表示
- 外部ライブラリ、サーバー、データベース不要

## 更新方法

`index.html`、`app.js`、`styles.css`を変更して`main`ブランチへ反映すると、GitHub Pagesの公開内容を更新できます。

## 注意

チェック状態はブラウザの`localStorage`に保存されます。別端末・別ブラウザには同期されません。
